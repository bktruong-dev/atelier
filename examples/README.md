# Example patterns

Open Atelier, press **+** for a new page, delete the starter code and paste any of these in. Each one makes its own dials with `dial()`, so they're ready to play with straight away.

| Pattern | What it shows |
|---|---|
| [fourier-epicycles.js](fourier-epicycles.js) | A heart, star or butterfly drawn by a chain of spinning circles (a Fourier series). The `circles` dial sets how many. |
| [game-of-life.js](game-of-life.js) | Conway's Game of Life, replayed from generation 0 every frame so it rewinds. Set `start` to 1 for Gosper's glider gun. |
| [strange-attractors.js](strange-attractors.js) | Aizawa, Thomas and Halvorsen attractors in 3D (`which` = 0, 1, 2). Orbit around them. |
| [ink-flow-field.js](ink-flow-field.js) | Hundreds of particles drifting through a turning flow field, like ink in water. Runs forever. |
| [planets-geocentric.js](planets-geocentric.js) | Every planet seen from a still Earth, with their retrograde loops. |
| [venus-geocentric.js](venus-geocentric.js) | Venus from Earth: the five-loop "pentagram of Venus" over 8 years. |
| [jellyfish.js](jellyfish.js) | A glowing jellyfish whose tentacles trail through where it has been. Rewind it and it swims backwards. |
| [navier-stokes-openai-2026.js](navier-stokes-openai-2026.js) | The vortex core of OpenAI's 2026 Navier–Stokes blow-up: streamlines integrated (Runge–Kutta) through an exactly incompressible velocity field with the paper's scalings — core radius τ^½, height τ^(½−h), speed τ^−(½+h) — collapsing and spinning up toward the singularity. The core's shape is a model; the scalings are the paper's. |
| [black-hole.js](black-hole.js) | A supermassive black hole seen from any angle, drawn the way the first black-hole image was (Luminet, 1979): light traced through Schwarzschild spacetime (d²u/dφ² = 3u² − u), each ring of the disc a smooth curve. The camera flies above and below the disc forever, each angle traced for real; the disc turns at Kepler speeds. `warmth` and `doppler` give the Interstellar look. |
| [black-hole-merger.js](black-hole-merger.js) | Two black holes spiralling together on Peters' gravitational-wave inspiral (a ∝ τ^¼, Φ ∝ τ^⅝), waves rippling out at light speed across a spacetime sheet, then merger and ringdown. Set `kind` to 1 for neutron stars and a kilonova. |
| [navier-stokes-blowup.js](navier-stokes-blowup.js) | An illustration of the swirling, collapsing vortex in OpenAI's reported 2026 Navier–Stokes blow-up construction (a model of its described shape, not the exact solution). |

Best viewed with **Glow** on and in **Cinema** (press C).
