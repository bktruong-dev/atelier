            Reference
            
The script runs again for every frame. Draw the picture for time t; scrubbing and rewinding just pick another t. Every dial is a variable you can use by name.

            

              
t, T
current time and duration, in seconds

              
duration(seconds)
length of the timeline (default 10). duration(Infinity) makes a pattern that never ends; then T is Infinity, so use t itself rather than t / T

              
view(radius)
how far from the centre is visible (default 2)

              
dot(x, y, z?)
a point

              
line(x1, y1, x2, y2) or line([x,y,z], [x,y,z])
a segment

              
path(points, closed?)
a curve through [[x, y, z?], …]

              
color(c)
"#86a8ff", "ink", "accent", hsl(h, s, l, a?) or r, g, b, a?

              
pointSize(px), strokeWidth(px)
sizes in screen pixels

              
dial(name, value, min, max, step?)
makes a slider from code (if it doesn't exist yet) and returns its value

              
orbit(yaw, pitch)
starting camera angle in degrees, for 3D

              
Math
sin cos sqrt PI … without Math., plus TAU PHI lerp clamp range random (seeded, so it is the same every frame)

            

            
Dials: ▶ animates one at its rate (units per second), bouncing, looping or once. Type past an end to stretch the range. Use z for 3D, then drag with Orbit on (or Shift) to turn it.

          

        

      

    


    

    
      

        
Welcome

        
How Atelier works

        
A notebook where a few lines of code become a moving picture. Math gives the shape, code gives the steps, and you choose how it looks.

      


      
    
        
  1. 
          
    A page is a canvas, dials and code
    
          
    The tabs along the top are pages. I and II are reference pages to read and play with. + starts a page of your own; it saves itself in this browser.
    
        
    2. 
        
  2. 
          
    Your code draws one moment
    
          
    The script runs again for every frame. t is the time in seconds and T the length of the timeline. Draw what the picture looks like at time t; play, rewind, scrub and speed just choose which t.
    
        
    3. 
        
  3. 
          
    Draw with a few words
    
          
    dot(x, y) a point · line(x1, y1, x2, y2) a segment · path(points) a curve through [[x, y], …] · color("#86a8ff") · pointSize(px) · strokeWidth(px). Math works without Math.: sin cos sqrt PI TAU PHI.
    
        
    4. 
        
  4. 
          
    Dials are variables
    
          
    + dial makes a slider; use its name in the code. ▶ animates it at its rate. + colour makes a colour for color(name).
    
        
    5. 
        
  5. 
          
    Go 3D
    
          
    Give points a third number, dot(x, y, z). Turn on Orbit (or hold Shift) and drag to walk around it; orbit(yaw, pitch) sets where the camera starts.
    
        
    6. 
        
  6. 
          
    Look closer
    
          
    Hover a point to read its x, y, z. Scroll to zoom, drag to pan. Cinema shows the pattern alone; ⚙ holds the settings.

The shape of almost every pattern


duration(10);          // seconds on the timeline
view(2);               // how much of the plane you see

const pts = [];
for (let s = 0; s <= TAU * t / T; s += 0.01) {
  const x = cos(3 * s);   // ← your formula
  const y = sin(2 * s);
  pts.push([x, y]);
}
path(pts);             // grows as t runs
